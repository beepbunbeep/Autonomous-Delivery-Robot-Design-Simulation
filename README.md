Hello!
Added here are all the files related to my autonomous delivery robot project. 

The design is fully functional, all is calculated and tested in MATLAB/SIMULINK Multibody.

The battery, driving, steering and drawer actuation motors have all be dimensioned and selected. These can be found in the provided documentation.

The documentation is currently only in Macedonian, as I made this for one of my classes however I will work on providing an English version for wider accessibility.
